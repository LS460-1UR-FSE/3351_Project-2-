
Linux Tome is a quick reference guide to Linux commands meant for beginners and experienced users who
would like to brush up on some of the standard, most used commands in Linux.

How to Run: 

1. Install Microsoft VS Code
2. Open project file in VS Code.  
3. Once open, right click on Index.html and click "Integrated Browser" option
(Note: Since this project uses a local JSON for the async data requirement, 
		it requires that the project be loaded in either VS Code Live Server or Github Pages.
		Opening the .html in a browser results in the HTML, Script, and CSS loading, but it will
		not be able to fetch the JSON containing all 20 commands.")


The data source was created by me, with COSC 2465 and Professor Lewis Heuermann used as a reference for the commands used.
